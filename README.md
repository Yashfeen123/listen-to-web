# ListenToWeb 🎙️

🔗 **Live Demo:** [Click Here to View Live App](https://listen-to-web-1.onrender.com/)

**ListenToWeb** is an AI-powered article-to-podcast converter web application. It allows users to paste any article link, select preferred voice accents or languages, and listen to or download server-compiled audio podcasts in real-time.

## Tech Stack
* **Backend:** Python (Flask)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite
* **Audio Generation:** Text-to-Speech (TTS) integration

## Features
* **Article URL Parser:** Extract text directly from web links.
* **Custom Accents & Voices:** Choose from multiple language accents (e.g., English Indian Accent).
* **Audio Streaming:** Play server-compiled MP3 files directly on the web platform.
* **Podcast Library:** Keep track of generated podcasts under "My Podcasts".

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/Yashfeen123/listen-to-web.git
```
2. Install the dependencies:
```bash
pip install -r requirements.txt
```
3. Run the Flask application:
```bash
python app.py
```
